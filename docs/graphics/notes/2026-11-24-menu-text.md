# Menu text at the sorted-widget draw

Research base `4d40837d1`. Reproduce each observation with
`h2 disasm <address> <instruction-count>` against the retail Xbox disc.

| Address | Evidence |
|---|---|
| `0x002538f5` | Text draw saves widget alpha at +0x64, asks slot +0x3c for the interface, multiplies its RGB at +8 by the widget RGB at +0x28, draws, then restores the interface RGB. |
| `0x00253ea8`, `0x002540a4` | Button draw handles its optional bitmap before calling the same interface draw with unmodified interface RGB. Both callers pass the rectangle twice for layout and clipping. |
| `0x0022f57f`, `0x00237607` | The respective text and button accessors return widget +0x74 and +0x70. Interface slot +8 at `0x0022f52e` returns its inline UTF-16 buffer at +0x44. The setters at `0x0022f50d` and `0x0022f545` bound the buffer to 32 or 256 units, including the terminator. |
| `0x0022e9c6`, `0x002363d4`, `0x002360c3` | The rectangle helper adds truncated animation X and Y using signed word-sized coordinates. The viewport helper adjusts split screens. The projection routine scales about the viewport centre using widget Z and the UI camera distance. |
| `0x0022cd48` | The interface draw reads the string through slot +8. A nonnegative reveal cursor at +0x3c replaces text and advances guest state. A nonzero tab count at +0x38 supplies explicit tab stops. |
| `0x0022ce44` | Interface flags at +0x14 control flash (bit 0), case conversion (bit 1) and suppression of the black shadow (bit 2). Flash multiplies alpha by half of one plus the cosine of the unsigned UI clock times the frequency at `0x0045e508`. |
| `0x0022ce8d`, `0x0013ed90`, `0x0013f2d7` | Interface +4 indexes the engine's font table. Interface +0x1c holds horizontal justification. The line renderer uses 1 for right, 2 for centre and 0 for left. |
| `0x0013ec70`, `0x0001f07f` | The font colour setter scales RGB together when all exceed the white level at `0x0045df00`. Glyph output requires both renderer enable checks, the active glyph ring and its bitmap. |
| `0x0013f4ab`, `0x0013f500` | The scanner packs face and shadow ARGB, multiplying each float component by 255 and truncating via `0x00322b0c`. Shadow alpha is capped at face alpha. |
| `0x0013f932`, `0x0001f530` | Each glyph is clipped before the quad callback. A nonzero shadow alpha draws that glyph first with the pixel scale added to X and Y, then draws the face at its original position. |
| `0x0022d2ee` | The substitution pass dispatches private-use units and checks named sequences from the alias table at `0x0044a3f0`. A resolved widget buffer can still need substitution. |
| `0x002539a8`, `0x0022d098`, `0x0022d0d3` | Separate globals select the widget index display and rectangle outlines. Even an empty normal string reaches the outline branch and the final tab-count reset. |

The reader accepts inline labels with the ordinary full-screen projection
and flags its unsupported text effects for guest drawing. Visible glyphs
also require shaped geometry and resident atlas pages.
