The inventory is below, read from code only. I did not run the game, so the `render.residual` callers table (grouped by return address at runtime) is not enumerated. The producer table is complete. Addresses are guest RVAs, written `0x…`.

Two things shape the whole answer:
- Every `impl.sim.native.*` switch defaults **Off** (`crates/hooking/hooks/src/switches/table.rs:97-111`). Only `impl.sim.present` and `impl.sim.sound-events` default On. In a default build the sim runs as lifted guest code, except for the object walks and the effects phase, which are always Rust.
- Render is mostly cut. `object_shadows`, `dynamic_lights` and `first_person` are cuts (`render-bridge/src/cut.rs:51-101`): their bodies never run. Their causes are `scene_dropped_*` or their own kept counters. The producer rows with a Partial or Kept status in `residual_census.rs:258-451` still run guest bodies.
