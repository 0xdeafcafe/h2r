# crates

Every crate in the workspace sits in a domain folder: `crates/<domain>/<crate>`.
A crate's domain is where it sits, and a crate may depend only on its own
domain and the ones its row allows. `scripts/crate-domains.toml` holds the
rules and `python3 scripts/crate-graph.py layers --check` enforces them.

| Folder | What lives there |
|---|---|
| [`formats/`](formats/) | Disc, tag and file formats, ours and the game's: plain data, no guest, no host. |
| [`recompiler/`](recompiler/) | XBE to host code: analysis, lifting, the IR, the C and Cranelift back ends and their oracles. |
| [`runtime/`](runtime/) | The machine the lifted code runs on: memory, CPU state, kernel HLE, filesystem, snapshots, the build-and-load driver. |
| [`platform/`](platform/) | The Xbox's devices and libraries on the host (Direct3D 8, DirectSound, XAPI, pads, Bink, voice) and the host graphics and audio under them. |
| [`hooking/`](hooking/) | How our code meets guest code: the hook registry, named points, typed guest layouts, switches. |
| [`rewrites/`](rewrites/) | Rust that replaces a guest subsystem: the native simulation, FrameScene, the native renderer, ported engine functions, and the bridges that install them. |
| [`live/`](live/) | Live, co-op, bots, films, cloud saves, telemetry and the dedicated host's data. |
| [`extensions/`](extensions/) | Features we add to the game: screens, skulls, the agent API, the debug menu, hot tag edits, the determinism harness. |
| [`tools/`](tools/) | Offline work on game data: the Halo 1 converters, the editor cores, the profiler. |
| [`apps/`](apps/) | What links a binary: the composition root, the `h2` command line, the desktop shell, the editor and the embedded hosts. |

Dependencies point down the list: `formats` uses nothing, `apps` may use
everything.
