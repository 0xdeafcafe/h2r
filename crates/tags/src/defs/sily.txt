# sily: one multiplayer game-variant setting the variant editor offers,
# named by a goof setting page. Evidence: crates/variants/src/schema.rs
# (SILY_* offsets, setting_def), docs/game/community-gametypes.md (layout
# read from the XBE at 0x2369b3, 0x236a3a).
group sily 0x24 align 4
  0x0 u32 setting -- E 0x2369b3 finds a setting's definition by it; variants/src/schema.rs SILY_SETTING
  0x4 unknown 0x4
  0x8 tagref strings groups=unic -- the unic the title, help and labels resolve in (datum at +0xc); variants/src/schema.rs SILY_UNIC
  0x10 string title -- V checked against the retail tag's text; variants/src/schema.rs SILY_TITLE
  0x14 string title_capitals -- the title in capitals, not used by our editor; variants/src/schema.rs (sily comment)
  0x18 string help -- V checked against the retail tag's text; variants/src/schema.rs SILY_HELP
  0x1c block options 0xc align 4 -- the values the setting offers; variants/src/schema.rs SILY_OPTIONS, OPTION_SIZE
    0x0 flags32 flags bits=default -- bit 0: the default choice; variants/src/schema.rs setting_def
    0x4 i32 value -- the value written to the variant record; variants/src/schema.rs setting_def
    0x8 string label -- resolved in the setting's unic; variants/src/schema.rs setting_def
